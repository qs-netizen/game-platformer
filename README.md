Procedural Platformer Game

A procedural 2D platformer made with Pygame Community Edition and Python.

This game features:

Procedural world generation
Random enemies
Infinite gameplay
Animated player
Tile-based platforms
Enemy collisions
Health system
Camera scrolling
Difficulty scaling
Features
Gameplay
Move left and right
Jump across platforms
Stomp enemies
Survive infinite generated worlds
Avoid falling into gaps
Procedural Generation
Random floating platforms
Random enemy spawning
Random ground gaps
Increasing difficulty every world
Graphics
Animated player
Tilemap rendering
Scrolling camera
Background rendering
Controls
Key	Action
A	Move Left
D	Move Right
SPACE	Jump
